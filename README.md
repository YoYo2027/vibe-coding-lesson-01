# Vibe Coding 第一课 · 互动教学网站

在线访问：https://yoyo2027.github.io/vibe-coding-lesson-01/

十个可以动手操作的场景，讲两件事：

- **大模型在做什么**：猜下一个词、一个词一个词地接龙、词向量、意义的加减法、“观其伴，知其义”、四步串起来
- **Vibe Coding 基础**：上下文决定输出、“像”不等于“对”、它不了解你的课堂，以及一次完整的“你说 → AI 写 → 你试”回放

上课时按 ← → 翻页，P 进入演示模式，N 打开讲者备注，F 全屏。

整个网站只有一个文件 `index.html`，下载后双击也能离线打开。页面里的概率、坐标和对话都是教学示意，不是真实模型的输出。

## 字体

页面内嵌了 Noto Serif SC 和 Noto Sans SC 的子集，英文使用 Libre Baskerville 和 JetBrains Mono（从 Google Fonts 加载）。这些字体都以 [SIL Open Font License 1.1](https://openfontlicense.org) 发布。
